# Apollo Hospital Analytics Dashboard | Power BI

## 📊 Project Overview
An interactive hospital analytics dashboard developed using Microsoft Power BI to explore hospital operations, patient information, admissions, and billing metrics.

## 🎯 Project Objectives
- Monitor hospital patient and admission metrics.
- Analyze patient demographics.
- Explore medical-condition distribution.
- Understand hospital stay and billing patterns.
- Present insights through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query (if used)
- Data Visualization
- Interactive Dashboard Design

## 📈 Dashboard Features
- Patient and admission KPI cards
- Patient demographic analysis
- Gender distribution
- Medical-condition analysis
- Hospital stay metrics
- Billing and revenue analysis
- Interactive filters and slicers

## 💡 Business Value
The dashboard provides a visual overview of hospital data and helps users explore patient, admission, and financial metrics to support operational analysis.
